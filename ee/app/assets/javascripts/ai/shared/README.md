---
title: AI Shared
---

This directory contains reusable code shared across multiple AI features.
Place code here when it needs to be used by more than one AI feature to avoid
duplication and keep behavior consistent.

## Structure

| Directory | Purpose |
| --------- | ------- |
| `feature_settings/` | Components and constants for AI feature configuration UI (model selection dropdowns, settings tables, batch update controls). |
| `utils/` | Utility functions shared across AI features (model data formatting, trusted URL computation). |
| `widgets/` | Small, self-contained UI components used in multiple AI features (status icons, quick actions). |
